          How to use Apprentice
          
          
          These are the actual workflows supported by the current system and this console.
          
        
          
      
          
      
          
        
          
          
          1
          
          
          Teach or register a capability
          
          
          Use the recorder + induction pipeline, or the built-in demo sandbox below, to create a reviewed playbook or read-only tool. Once activated, it shows up in the capability ledger.
          
        
          
        
          
          
          2
          
          
          Rehearse the run offline
          
          
          The twin must produce a passing action plan before the run can cross the approval boundary. This console shows the stored actions and the six invariant checks.
          
        
          
        
          
          
          3
          
          
          Activate, approve, veto, monitor
          
          
          From here you can activate a rehearsed run, approve or reject pending runs, cancel a veto window, and track trust promotions or demotions over time.
          
        
          
      
          
    
          

    
          
      
          
        
          
          
          Create a run
